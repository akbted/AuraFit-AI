# AuraFit AI - Real-time Workout Tracker

AI-powered fitness tracking using computer vision.

## Features
- Push-ups, Squats, Crunches, Leg Raises counting
- Plank hold timer
- Real-time feedback
- Form analysis

## Usage
1. Allow camera access
2. Select an exercise
3. Click "Start Session"
4. Exercise and get real-time feedback!
